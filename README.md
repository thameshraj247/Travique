# Travique — Luxury Travel & Holiday Package Platform

A travel agency and holiday package website built with the **Deep Ocean Blue (`#07192F`) + Tropical Teal (`#00B4D8` / `#00A896`)** palette.

---

## 🌟 Highlights & Key Features

### 1. Header & Navigation (Exact Specification)
- **Left**: Travique Origami Plane Logo Icon + Brand Title **Travique** with subtitle `LUXURY HOLIDAYS`.
- **Middle Nav Tags**:
  - `Home`
  - `About`
  - `Domestic`
  - `International`
  - `Honeymoon & Family`
  - `Contact`
  - `Dashboard` (with real-time live trip indicator)
- **Right Side Controls**:
  - **LTR / RTL Button**: Instant bi-directional toggle (`dir="rtl"` / `dir="ltr"`), mirroring layout for internationalized reading.
  - **Dark Mode Button**: Switches between Deep Ocean Blue night mode and crisp coastal daylight mode with persistent `localStorage` storage.
  - **Login Button / Traveler Profile**: Seamless login portal with 1-click demo access for **Sophia Vance (Diamond Club Traveler)**, avatar dropdown, and sign-out.

---

### 2. Comprehensive Traveler Dashboard (`Dashboard: Yes`)
- **Active Bookings & Live Milestone Tracker**:
  - Tracks status in real time: `Confirmed` ➔ `Visa & Vouchers` ➔ `E-Tickets Issued` ➔ `Ready to Fly`.
  - Shows flight PNR, airlines, hotel vouchers, and traveler counts.
- **Interactive Day-by-Day Itinerary Viewer**:
  - Timeline cards with hours, descriptions, and Travique Signature Exclusives (underwater dining, scenic seaplane transfers, helicopter tours).
  - Multi-trip selector (Maldives Sanctuary, Swiss Alpine Grand Odyssey, Kashmir Paradise).
- **Saved Packages (Wishlist)**:
  - Real-time wishlist synced with package cards across the site.
  - 1-click remove, clear all, and direct booking.
- **Documents Vault (Tickets & Invoices)**:
  - **Official E-Ticket / Boarding Pass Modal**: Airline-grade pass with PNR, flight sectors, hotel voucher PIN, barcode, and QR code with **1-click printable / save-to-PDF layout**.
  - **Official Tax Invoice Modal**: Itemized travel breakdown, taxes, payment confirmation, and authorized seal with **1-click printable / save-to-PDF layout**.

---

### 3. Holiday Packages & Portals
- **Home**: Inspiring hero with dynamic search filter bar, top curated destinations, trending packages, why choose Travique, smart budget calculator, and verified traveler reviews.
- **Domestic Packages**: Kashmir, Kerala Backwaters, Royal Rajasthan, Goa Coastal Luxury, Ladakh Pangong Lake, and Andaman Coral Islands.
- **International Packages**: Swiss Alps Glacier Express, Maldives Lagoon Sanctuary, Bali Rainforest & Seminyak, Dubai Future City & Desert Safari, Japan Golden Route, and Paris & Rome Odyssey.
- **Honeymoon & Family Tours**: Dual-tab experience switching between *Romantic Honeymoon Escapes* and *Family Fun & Adventure*.
- **About Us**: Travique story, certified IATA & ATOL memberships, and carbon-neutral travel pledge.
- **Contact Us**: 24/7 hotline, WhatsApp concierge button, global lounge addresses, and interactive trip inquiry form.

---

## 🚀 How to Run the Website

Simply double-click or open `index.html` in any modern web browser (Edge, Chrome, Safari, Firefox).
No build step or server installation is required.
